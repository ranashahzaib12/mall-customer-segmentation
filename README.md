# 🛍️ Mall Customer Segmentation

Segment mall customers based on **Gender, Age, Annual Income**, and **Spending Score** using **KMeans Clustering**, and visualize the results with an interactive **Streamlit** app.

---

## 📌 Features

- 🔍 Predicts customer segment (1 out of 5 clusters)
- 📊 Interactive data visualization with scatter plots
- 🎛️ Real-time inputs via Streamlit sliders and dropdowns
- 💾 Model training script + saved models (.pkl files)
- 📁 Clean modular structure for easy deployment

---

## 🧠 Technologies Used

- Python 3.10+
- pandas
- scikit-learn
- matplotlib
- Streamlit
